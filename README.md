\# Math Expression Evaluator



A JavaScript-based Math Expression Evaluator developed using Node.js. This project demonstrates expression parsing, arithmetic operations, operator precedence, parentheses handling, and invalid expression detection.



\## Features



\- Addition and subtraction

\- Multiplication and division

\- Operator precedence handling

\- Parentheses support

\- Invalid expression detection

\- Division-by-zero handling

\- JSON-formatted output

\## Requirements



\- Node.js installed on your computer

\- A terminal or Command Prompt



\## How to Run



Open Command Prompt in the project directory and run any problem file:



```bash

node problem1.js

node problem2.js

node problem3.js

node problem4.js

node problem5.js

```



Follow each program's expected input format.



\## Example



For the expression:



```text

(2 + 3) \* 4

```



Expected result:



```text

20

```



For division by zero, the final evaluator returns an invalid-expression result.
